# Proofly

Proofly is an AI immigration document and O-1 evidence copilot built for Open Atlas 2026.

## Hackathon Scope

- Upload and process immigration documents
- Create a status and compliance timeline
- Map supporting evidence to O-1A criteria
- Answer questions using user documents and official sources

## Technology

- React
- FastAPI
- Supermemory
- Featherless
- Tavily
